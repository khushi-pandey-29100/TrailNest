# TrailNest

TrailNest is a trekking and travel booking website built using PHP and MySQL.

## Features

- Browse trekking routes
- View trek details
- Trek reviews
- Booking system
- Contact/enquiry form
- Admin panel
- MySQL database
- Responsive web interface

## Technologies Used

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap

## Live Website

https://trailnest.freepage.cc/

## Admin Panel

https://trailnest.freepage.cc/admin/

## Project Setup

1. Clone the repository.
2. Create a MySQL database.
3. Import `database_live.sql`.
4. Copy `includes/config.example.php` to `includes/config.php`.
5. Add your own database credentials to `includes/config.php`.
6. Start Apache and MySQL using XAMPP.
7. Open the project in your browser.

## Security

Database credentials are not included in this repository.
Use `includes/config.example.php` as a template for configuration.
